Generated by `scripts/build_measure_guide.py` from the model and both reports; never edited by hand. Example values come from the model with Power BI Desktop open (`python scripts/build_measure_guide.py --capture`) and are for the year 2025 unless the example says otherwise. The column-by-column reference is the [data dictionary](data-dictionary.md).

## Emissions

Totals of tonnes of carbon dioxide equivalent (tCO2e), location-based, from the five emission tables.

### Total Emissions (tCO2e)

**What it is.** Tonnes of CO2 equivalent, location-based: scope 1, scope 2 location-based and the scope 3 categories held (1; 3 parts a and c; 4; 5 landfill only; 6 flights only; 9; 11 outside Rest of world), from the stored tco2e columns of the five emission tables. Market-based scope 2 is a separate measure and is never added in.

**What it does.**

```dax
SUM ( fact_emissions[tco2e] ) + SUM ( fact_energy_upstream[tco2e] ) + SUM ( fact_purchases[tco2e] ) + SUM ( fact_freight[tco2e] ) + SUM ( fact_use_phase[tco2e] )
```

Reads `fact_emissions[tco2e]`, `fact_energy_upstream[tco2e]`, `fact_purchases[tco2e]`, `fact_freight[tco2e]`, `fact_use_phase[tco2e]`. Format `#,0.0`.

## Time comparison

The same months a year earlier, and the change on them, like for like or including new sites.

### Emissions Prior Year (tCO2e)

**What it is.** Emissions for the same months one year earlier. dim_date has one row per month, so it can't be marked as a date table and SAMEPERIODLASTYEAR doesn't apply; this shifts each month key back a year instead (20250301 to 20240301).

**What it does.**

```dax

VAR PriorKeys =
	SELECTCOLUMNS ( VALUES ( dim_date[date_key] ), "date_key", dim_date[date_key] - 10000 )
RETURN
	CALCULATE ( [Total Emissions (tCO2e)], REMOVEFILTERS ( dim_date ), TREATAS ( PriorKeys, dim_date[date_key] ) )
```

Builds on [Total Emissions (tCO2e)](#total-emissions-tco2e). Reads `dim_date[date_key]`. Format `#,0.0`.

**How it is used.**

- Example (year 2025): 1,456,602.1
- Used by [Emissions Change vs Prior Year (%)](#emissions-change-vs-prior-year-), [Emissions Change Including New Sites (tCO2e)](#emissions-change-including-new-sites-tco2e), [Emissions Change Including New Sites (%)](#emissions-change-including-new-sites-)

### Emissions Change vs Prior Year (%)

**What it is.** Like-for-like change against the same months a year earlier: only site-months with emissions in both years count, so a site that opened partway through (Tartu, July 2024) or months with no prior year (2023) don't inflate the change. Shown as a percentage; blank when nothing is comparable.

**What it does.**

```dax

VAR Comparable =
	FILTER (
		CROSSJOIN ( VALUES ( dim_site[site_id] ), VALUES ( dim_date[date_key] ) ),
		NOT ISBLANK ( CALCULATE ( [Total Emissions (tCO2e)] ) )
			&& NOT ISBLANK ( CALCULATE ( [Emissions Prior Year (tCO2e)] ) )
	)
VAR CurrentYear = SUMX ( Comparable, CALCULATE ( [Total Emissions (tCO2e)] ) )
VAR PriorYear = SUMX ( Comparable, CALCULATE ( [Emissions Prior Year (tCO2e)] ) )
RETURN
	DIVIDE ( CurrentYear - PriorYear, PriorYear )
```

Builds on [Total Emissions (tCO2e)](#total-emissions-tco2e), [Emissions Prior Year (tCO2e)](#emissions-prior-year-tco2e). Reads `dim_site[site_id]`, `dim_date[date_key]`. Format `0.0%`.

**How it is used.**

- Example (year 2025): -2.3%
- Shown in Emissions report > Intensity and growth: chart "Like-for-like change on the prior year, by site (%)"
- Shown in Emissions report > What changed: chart "Change on the prior year, each year (%)"
- Shown in Emissions report > What changed: matrix "Like-for-like change by site, each year (%)"
- Shown in Emissions report > Sites: table "Emissions and intensity by site: 'all' includes use of the products a plant made"
- Used by [What Changed Message](#what-changed-message)

### Emissions Change Including New Sites (tCO2e)

**What it is.** Plain change against the same months a year earlier, counting every site, so a new site's whole first year counts as an increase (Tartu, July 2024). Only months whose prior year is in the data count, so 2023 is blank. Sums across sites to the company change; set it beside the like-for-like Emissions Change vs Prior Year (%).

**What it does.**

```dax

VAR AllKeys = ALL ( dim_date[date_key] )
VAR Months =
	FILTER ( VALUES ( dim_date[date_key] ), ( dim_date[date_key] - 10000 ) IN AllKeys )
RETURN
	IF (
		NOT ISEMPTY ( Months ),
		SUMX ( Months, CALCULATE ( [Total Emissions (tCO2e)] ) - CALCULATE ( [Emissions Prior Year (tCO2e)] ) )
	)
```

Builds on [Total Emissions (tCO2e)](#total-emissions-tco2e), [Emissions Prior Year (tCO2e)](#emissions-prior-year-tco2e). Reads `dim_date[date_key]`. Format `#,0.0`.

**How it is used.**

- Example (year 2025): -32,635.5
- Shown in Emissions report > What changed: chart "Change on the prior year by site, 2024 and 2025 (tCO2e)"
- Shown in Emissions report > What changed: waterfall "What moved emissions: change by site on the prior year (tCO2e)"
- Used by [Emissions Change Including New Sites (%)](#emissions-change-including-new-sites-), [What Changed Message](#what-changed-message)

**What it is.** Emissions Change Including New Sites (tCO2e) as a share of the prior year's emissions. Blank when nothing is comparable.

### Total Emissions Market-based (tCO2e)

**What it is.** Total Emissions with market-based scope 2 in place of location-based scope 2. Scopes 1 and 3 are the same in both totals.

**What it does.**


### Price Effect (EUR)

**What it is.** ACCA F5 sales variances with the prior year as standard: actual = this period, standard = the same months a year earlier, compared product by product over products sold in both. Price effect = (actual price - prior-year price) x actual units. The joint price-times-volume piece sits here, as most textbooks place it (Sorochuk, Vinroot and Leemis, 2023).

**What it does.**

```dax

VAR Products =
	ADDCOLUMNS (
		VALUES ( dim_product[product_id] ),
		"@AU", [Units Sold], "@PU", [Units Sold Prior Year],
		"@S", [Net Sales (EUR)], "@PS", [Net Sales Prior Year (EUR)],
		"@C", [Cost of Sales (EUR)], "@PC", [Cost of Sales Prior Year (EUR)]
	)
VAR Comparable = FILTER ( Products, NOT ISBLANK ( [@AU] ) && NOT ISBLANK ( [@PU] ) )
RETURN
	SUMX ( Comparable, [@S] - DIVIDE ( [@PS], [@PU] ) * [@AU] )
```

### Mix Effect (EUR)

**What it is.** ACCA F5 sales variances with the prior year as standard: actual = this period, standard = the same months a year earlier, compared product by product over products sold in both. Mix effect = (actual units - actual total units in the prior-year mix) x prior-year margin per unit, measured on units (ACCA examiner's report, June 2020). Across very different products (pumps and spare parts) it is large and offset by quantity: read it within one family.

**What it does.**

```dax

VAR Products =
	ADDCOLUMNS (
		VALUES ( dim_product[product_id] ),
		"@AU", [Units Sold], "@PU", [Units Sold Prior Year],
		"@S", [Net Sales (EUR)], "@PS", [Net Sales Prior Year (EUR)],
		"@C", [Cost of Sales (EUR)], "@PC", [Cost of Sales Prior Year (EUR)]
	)
VAR Comparable = FILTER ( Products, NOT ISBLANK ( [@AU] ) && NOT ISBLANK ( [@PU] ) )
VAR TotalAU = SUMX ( Comparable, [@AU] )
VAR TotalPU = SUMX ( Comparable, [@PU] )
RETURN
	SUMX ( Comparable, ( [@AU] - TotalAU * DIVIDE ( [@PU], TotalPU ) ) * DIVIDE ( [@PS] - [@PC], [@PU] ) )
```

### Quantity Effect (EUR)

**What it is.** ACCA F5 sales variances with the prior year as standard: actual = this period, standard = the same months a year earlier, compared product by product over products sold in both. Quantity effect = (actual total units in the prior-year mix - prior-year units) x prior-year margin per unit.

**What it does.**

```dax

VAR Products =
	ADDCOLUMNS (
		VALUES ( dim_product[product_id] ),
		"@AU", [Units Sold], "@PU", [Units Sold Prior Year],
		"@S", [Net Sales (EUR)], "@PS", [Net Sales Prior Year (EUR)],
		"@C", [Cost of Sales (EUR)], "@PC", [Cost of Sales Prior Year (EUR)]
	)
VAR Comparable = FILTER ( Products, NOT ISBLANK ( [@AU] ) && NOT ISBLANK ( [@PU] ) )
VAR TotalAU = SUMX ( Comparable, [@AU] )
VAR TotalPU = SUMX ( Comparable, [@PU] )
RETURN
	SUMX ( Comparable, ( TotalAU * DIVIDE ( [@PU], TotalPU ) - [@PU] ) * DIVIDE ( [@PS] - [@PC], [@PU] ) )
```

Builds on [Units Sold](#units-sold), [Units Sold Prior Year](#units-sold-prior-year), [Net Sales (EUR)](#net-sales-eur), [Net Sales Prior Year (EUR)](#net-sales-prior-year-eur), [Cost of Sales (EUR)](#cost-of-sales-eur), [Cost of Sales Prior Year (EUR)](#cost-of-sales-prior-year-eur). Reads `dim_product[product_id]`. Format `#,0`.

**How it is used.**

- Example (year 2025): 15,455,653
- Used by [Volume Effect (EUR)](#volume-effect-eur), [Quantity Effect by Group (EUR)](#quantity-effect-by-group-eur), [Bridge Value (EUR)](#bridge-value-eur), [Price Volume Mix Message](#price-volume-mix-message)

**What it does.**

```dax

```
